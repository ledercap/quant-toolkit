# Sectors

Research built on the toolkit. One folder per sector; inside, one file per topic:

- `market-sizing.md`
- `players.md` (largest players internationally, including the blue-chip tier)
- `pick-and-shovel.md` (the components and suppliers that go into each)
- `coverage/` (analyst coverage on selected companies, one file per company)

Starting with `space/` and `robotics/`. Every figure cites its source and date.
